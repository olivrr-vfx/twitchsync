Funktionen

Gebaut für Multistream-Abende.

Alles, was man braucht, wenn mehrere Streamer gemeinsam live sind – und nichts, was im Weg steht.

Auto-Sync auf die Zehntelsekunde

Jeder Stream meldet seine Latenz zum Streamer. TwitchSync gleicht alle an den langsamsten an: schnellere Streams spielen kurz minimal langsamer oder halten exakt so lange an, wie nötig. Haben alle genug Puffer, holt die Gruppe gemeinsam auf – die Verzögerung wächst nicht dauerhaft.

Facecam-Modus

Ein Stream als großes Gameplay, alle anderen nur als Facecam – automatisch erkannt und zugeschnitten.

Ton per Klick

Klick auf einen Stream gibt ihm den Ton, alle anderen werden stumm. ⌥-Klick mischt weitere dazu, Lautstärke pro Stream.

Dein Twitch-Login

Einmal normal bei twitch.tv anmelden – Turbo, Abo-Werbefreiheit und Sub-Emotes wirken in allen Playern und im Chat.

Multistream-Erkennung

Stream Together, Shared Chat und Erwähnungen im Titel: Live-Partner erscheinen in der Kachel – mit „Alle öffnen“.

Chat mit Tabs

Popout-Chat pro Kanal, ein-/ausklappbar, folgt auf Wunsch dem Stream, den du gerade hörst.

Werbe- & Tracking-Blocker

Blockiert bekannte Werbe- und Tracker-Domains, lädt auf Wunsch entpackte Erweiterungen wie uBlock Origin.

Nichts verdeckt das Bild

Kanalname, Latenz und Bedienelemente sitzen in einer schmalen Leiste über dem Video statt darauf. Wer es ganz clean mag, blendet mit einer Taste alle Infos aus – inklusive der Twitch-Steuerleiste. Das Grid maximiert jede Kachel in 16:9, Doppelklick schaltet in den Fokus-Modus.

Wie Sync funktioniert

Messen. Bremsen. Gleichziehen.

Latenz messen

Der offizielle Twitch-Player meldet hlsLatencyBroadcaster. Kombiniert mit der Wiedergabeposition ergibt das eine glatte, jederzeit genaue Latenz pro Stream.

Ziel bestimmen

Der Stream mit der höchsten Latenz ist die Referenz – inklusive deines manuellen Versatzes (±0,1 s / ±1 s pro Stream).

Angleichen

Kleine Abstände: bis 0,9× verlangsamen, Tonhöhe bleibt. Große Abstände: für exakt die fehlende Zeit anhalten – im Player selbst getimt.

Gemeinsam aufholen

Haben alle genug Puffer, beschleunigt die ganze Gruppe synchron auf bis zu 1,08×. Werbepausen und Nachladen werden erkannt und ausgeklammert.

Facecam-Modus

Ein Gameplay. Alle Reaktionen.

Wähle einen Stream als Hauptbild – alle anderen schrumpfen auf ihre Webcam. TwitchSync nimmt dafür mehrere Standbilder, sucht Gesichter (auf macOS über Apples Vision-Framework) und wählt das, das immer an derselben Stelle auftaucht: Gesichter im Gameplay springen herum, die Facecam nicht.

Der Ausschnitt wird automatisch nachgeführt. Liegt die Erkennung daneben, ziehst du den Rahmen im Editor einfach selbst – pro Kanal gemerkt. Doppelklick auf eine Facecam macht sie zum Hauptbild.

Installation

In zwei Minuten startklar.

1 · Herunterladen

Lade unter Releases die DMG für deinen Mac (arm64 = Apple Silicon, x64 = Intel) und ziehe TwitchSync in „Programme“.

2 · Erster Start

Die App ist nicht von Apple notarisiert. Beim ersten Start: Rechtsklick auf TwitchSync → „Öffnen“ → „Öffnen“. Alternativ im Terminal:

xattr -dr com.apple.quarantine /Applications/TwitchSync.app

3 · Loslegen

Optional bei Twitch anmelden (für gefolgte Kanäle, Turbo & Sub-Emotes), oben Kanäle eintippen – oder twitch.tv-Links aufs Fenster ziehen.

Selbst bauen

Node.js 18+ vorausgesetzt. Kein Build-Schritt für den Code – nur Electron.

git clone https://github.com/olivrr-vfx/twitchsync.git
cd twitchsync && npm install
npm start          # App starten
npm run pack       # .app bauen  →  dist/mac-arm64/TwitchSync.app
npm run dist       # DMG + ZIP für Apple Silicon und Intel

Datenschutz

Keine eigenen Server, keine Telemetrie. Das Passwort tippst du direkt bei twitch.tv ein; gespeichert wird nur Twitchs Sitzungs-Cookie in deinem Benutzerordner.

FAQ

Gut zu wissen.

Ist TwitchSync werbefrei?

Werbefreiheit kommt von deinem Twitch-Konto: Mit Turbo überall, mit einem Abo beim jeweiligen Kanal. Der eingebaute Blocker sperrt Werbe- und Tracking-Domains, verändert aber bewusst nicht den Videostream. Läuft trotzdem eine Werbepause, nimmt TwitchSync den Stream so lange aus der Synchronisation.

Wie genau ist die Synchronisation?

Im Test lagen sechs gleichzeitige Streams nach 20 Sekunden innerhalb von ±0,1 s. Die Genauigkeit hängt von Twitchs Latenzmessung ab; der Rest lässt sich pro Stream in 0,1-s-Schritten feinjustieren – nützlich, wenn ein Streamer selbst eine Verzögerung eingestellt hat.

Warum ist ein Stream plötzlich kurz eingefroren?

Das ist der Sync: Liegt ein Stream mehr als 1,5 s vor den anderen, hält er für genau diese Zeit an. Beim Stream mit Ton wird lieber sanft verlangsamt. Beides ist in den Einstellungen anpassbar.

Die Facecam wird nicht erkannt – was tun?

Die Erkennung braucht ein sichtbares Gesicht. Bei Streamern ohne Kamera, mit VTuber-Avatar oder wechselnden Szenen auf den Facecam-Chip bzw. „Ausschnitt anpassen“ klicken und den Rahmen selbst setzen.

Ist das ein offizielles Twitch-Produkt?

Nein. TwitchSync ist ein inoffizielles Open-Source-Projekt und nicht mit Twitch Interactive, Inc. verbunden. Streams laufen über den offiziellen eingebetteten Twitch-Player.
